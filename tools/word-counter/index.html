How to Create a Strong Password

  1. Choose a password length of at least 12 characters.
  2. Include uppercase and lowercase letters.
  3. Include numbers.
  4. Include symbols when supported by the website.
  5. Avoid using the same password on multiple accounts.

Why Use a Random Password?

Random passwords are generally harder to guess than predictable passwords based on names, dates or common words. Using a different password for each important account also limits the impact of a compromised password.

Password Security Tips

  • Use a unique password for every important account.
  • Prefer longer passwords.
  • Do not share passwords with other people.
  • Consider using a reputable password manager.
  • Enable multi-factor authentication when available.

Frequently Asked Questions

Is this password generator free?

Yes. The password generator is free to use.

Are generated passwords stored?

The generator creates passwords directly in your browser and does not require them to be uploaded to a server.

How long should a password be?

Longer passwords generally provide more resistance to guessing and brute-force attacks. For important accounts, using a long unique password is preferable to a short predictable one.

Should I use the same password everywhere?

No. Use unique passwords for different accounts so that one compromised password does not automatically expose your other accounts.
